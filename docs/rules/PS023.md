# PS023 — POSIX_VAR_EXPANSION

**Severity** `warn` · **Confidence** `medium` · **Affected targets** `cmd`

`$VAR` / `${VAR}` do not expand under cmd.exe (which uses `%VAR%`).

## Why it breaks

- POSIX shells expand $VAR/${VAR}. ([source](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/V3_chap02.html#tag_18_05_02))
- cmd.exe expands %VAR%; $VAR stays literal. ([source](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/set_1))

## Bad examples

- `echo $npm_package_version`
- `node build.js --out ${OUT_DIR:-dist}`
- `ls $HOME`

## Good examples

- `node -e "console.log(process.env.npm_package_version)"`
- `npm run print-version`

## False positives

Medium confidence by design: cmd users may run via a custom script-shell, and npm_* variables are sometimes only needed on Unix. `$env:` forms belong to PS003; `$(…)` to PS020.

## Fix (manual)

Manual: explained only — never applied automatically.
