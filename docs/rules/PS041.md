# PS041 — PLATFORM_EXE_SUFFIX

**Severity** `warn` · **Confidence** `high` · **Affected targets** `posix-sh`

Invoking .bat/.cmd/.exe/.ps1 files ties the script to Windows.

## Why it breaks

- .bat/.cmd/.exe are Windows executable formats; POSIX systems cannot run them directly. ([source](https://en.wikipedia.org/wiki/Batch_file))

## Bad examples

- `build.cmd`
- `scripts\deploy.bat`
- `tool.exe --flag`

## Good examples

- `node scripts/deploy.js`
- `cross-platform-bin --flag`

## False positives

Only the invoked command (argv[0]) is checked — .bat/.cmd/.exe paths passed as arguments are data, not invocations. Intentional Windows-only steps should be suppressed via config.

## Fix (manual)

Manual: explained only — never applied automatically.
