# PS031 — EXPLICIT_CMD

**Severity** `warn` · **Confidence** `high` · **Affected targets** `posix-sh`

`cmd /c …` ties the script to Windows and fails on macOS/Linux.

## Why it breaks

- cmd.exe is the Windows command interpreter; it does not exist on macOS/Linux. ([source](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/cmd))

## Bad examples

- `cmd /c "set FOO=bar&& node app.js"`
- `cmd /c dir`

## Good examples

- `node app.js`
- `ls`

## False positives

Wrapper payloads are never re-analyzed. Intentional Windows-only scripts should be suppressed via config, not restructured by the linter.

## Fix (manual)

Manual: explained only — never applied automatically.
