# PS011 — POSIX_CP

**Severity** `error` · **Confidence** `high` · **Affected targets** `cmd`

`cp` / `cp -r` is not available in native Windows npm scripts.

## Why it breaks

- cmd.exe uses copy/xcopy/robocopy; `cp` is not recognized. ([source](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/copy))

## Bad examples

- `cp -r src dist`
- `cp a.txt b.txt`

## Good examples

- `shx cp -r src dist`
- `node -e "require('fs').cpSync('src','dist',{recursive:true})"`

## False positives

Not reported for `shx cp …` or cp inside strings/wrapper payloads.

## Fix (conditional)

Conditional: applied only when the required dependency is already installed; otherwise surfaced as a plan. `--fix` never installs dependencies.
