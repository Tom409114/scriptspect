# PS016 — POSIX_WHICH

**Severity** `error` · **Confidence** `high` · **Affected targets** `cmd`

`which` is not available in native Windows npm scripts (cmd.exe uses `where`).

## Why it breaks

- cmd.exe ships where.exe; there is no which. ([source](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/where))

## Bad examples

- `which node`
- `which python3`

## Good examples

- `node -e "console.log(process.execPath)"`
- `npx which-node`

## False positives

PowerShell users often alias which; the default npm script shell on Windows is cmd.exe, which has where.exe only.

## Fix (manual)

Manual: explained only — never applied automatically.
