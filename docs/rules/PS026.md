# PS026 — UNIX_PATH_ASSUMPTION

**Severity** `advisory` · **Confidence** `medium` · **Affected targets** `cmd`, `powershell`

Hardcoded Unix paths (/tmp, /usr/bin, …) do not exist on Windows.

## Why it breaks

- Windows has no /tmp or /usr; equivalents live under %TEMP%, %ProgramFiles%. ([source](https://learn.microsoft.com/en-us/windows/deployment/usmt/usmt-recognized-environment-variables))

## Bad examples

- `cp x /tmp/`
- `mkdir /usr/local/etc/app`

## Good examples

- `mktemp -d`
- `node scripts/tmpdir.js`

## False positives

Advisory only: absolute Unix paths are occasionally passed as opaque arguments to tools that interpret them elsewhere. Paths like /api used as URLs must not match (they do not: prefix list covers filesystem roots only).

## Fix (manual)

Manual: explained only — never applied automatically.
