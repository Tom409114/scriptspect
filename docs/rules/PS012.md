# PS012 — POSIX_MV

**Severity** `error` · **Confidence** `high` · **Affected targets** `cmd`

`mv` is not available in native Windows npm scripts.

## Why it breaks

- cmd.exe uses move; `mv` is not recognized. ([source](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/move))

## Bad examples

- `mv dist build`
- `mv old.json new.json`

## Good examples

- `shx mv dist build`
- `node -e "require('fs').renameSync('a','b')"`

## False positives

Not reported for `shx mv …` or mv inside strings/wrapper payloads.

## Fix (conditional)

Conditional: applied only when the required dependency is already installed; otherwise surfaced as a plan. `--fix` never installs dependencies.
