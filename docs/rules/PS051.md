# PS051 — TARGET_SHELL_PARSE_ERROR

**Severity** `advisory` · **Confidence** `medium` · **Affected targets** `posix-sh`, `cmd`, `powershell`

The script is invalid or outside the supported analyzer subset for an active shell.

## Why it breaks

- Shell quoting, grouping, expansion, and redirection syntax must be structurally complete. ([source](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/V3_chap02.html))

## Bad examples

- `echo 'unterminated`
- `echo ${UNTERMINATED`

## Good examples

- `echo "complete"`
- `node scripts/build.js`

## False positives

Deterministic syntax failures are error/high. Supported-subset boundaries are advisory/medium and conservatively gate automatic replacements.

## Fix (manual)

Manual: explained only — never applied automatically.
