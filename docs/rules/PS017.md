# PS017 — POSIX_GREP

**Severity** `warn` · **Confidence** `high` · **Affected targets** `cmd`

`grep` is not available in native Windows npm scripts.

## Why it breaks

- cmd.exe ships findstr, not grep. ([source](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/findstr))

## Bad examples

- `grep -r "TODO" src`
- `cat x | grep y`

## Good examples

- `shx grep -r "TODO" src`
- `node scripts/search.js`

## False positives

Not reported for `shx grep …` or grep inside strings/wrapper payloads.

## Fix (conditional)

Conditional: applied only when the required dependency is already installed; otherwise surfaced as a plan. `--fix` never installs dependencies.
