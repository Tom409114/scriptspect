# PS032 — EXPLICIT_POWERSHELL

**Severity** `warn` · **Confidence** `high` · **Affected targets** `posix-sh`

powershell/pwsh wrappers assume PowerShell exists (missing on stock macOS/Linux).

## Why it breaks

- PowerShell is preinstalled on Windows only; macOS/Linux need a manual install. ([source](https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell))

## Bad examples

- `powershell -Command "echo hi"`
- `pwsh -File ./build.ps1`

## Good examples

- `node ./build.js`
- `node scripts/build.mjs`

## False positives

Wrapper payloads are never re-analyzed. macOS can install pwsh, but a stock environment does not ship it.

## Fix (manual)

Manual: explained only — never applied automatically.
