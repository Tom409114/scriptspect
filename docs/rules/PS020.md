# PS020 — COMMAND_SUBSTITUTION

**Severity** `error` · **Confidence** `high` · **Affected targets** `cmd`

`$(…)` command substitution is POSIX-only and fails under cmd.exe.

## Why it breaks

- $( ) command substitution is defined by POSIX shell. ([source](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/V3_chap02.html#tag_18_06_03))
- cmd.exe has no command substitution; it uses for /f with delayed expansion at best. ([source](https://learn.microsoft.com/en-us/previous-versions/windows/it-pro/windows-server-2012-r2-and-2012/cc772390(v=ws.11)))

## Bad examples

- `node $(npm bin)/jest`
- `echo "built at $(date)"`
- `rm -rf $(ls dist)`

## Good examples

- `npx jest`
- `node scripts/run.js`

## False positives

Not reported inside explicit shell wrappers (PS030 owns those), and substitution contents are not scanned for other rules (no double reporting).

## Fix (manual)

Manual: explained only — never applied automatically.
