# PS018 — POSIX_SED

**Severity** `warn` · **Confidence** `high` · **Affected targets** `cmd`

`sed` is not available in native Windows npm scripts.

## Why it breaks

- cmd.exe ships no sed equivalent. ([source](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/windows-commands))

## Bad examples

- `sed -i 's/foo/bar/' file.txt`
- `sed 's/a/b/g' x > y`

## Good examples

- `node scripts/replace.js`
- `shx sed "s/a/b/g" x`

## False positives

Not reported for `shx sed …` or sed inside strings/wrapper payloads.

## Fix (conditional)

Conditional: applied only when the required dependency is already installed; otherwise surfaced as a plan. `--fix` never installs dependencies.
