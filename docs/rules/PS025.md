# PS025 — DEV_NULL

**Severity** `warn` · **Confidence** `high` · **Affected targets** `cmd`, `powershell`

Redirecting to /dev/null fails on Windows (the device is NUL).

## Why it breaks

- Windows null device is NUL; /dev/null does not resolve. ([source](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/microsoft-windows-commands))

## Bad examples

- `node heavy.js > /dev/null`
- `cmd 2> /dev/null`

## Good examples

- `node scripts/quiet.js`
- `node heavy.js > build.log`

## False positives

Only tokens equal to /dev/null (or a /dev/null path suffix) match; documentation strings mentioning /dev/null inside larger quoted prose are still reported — suppress via config if intentional.

## Fix (manual)

Manual: explained only — never applied automatically.
