# PS040 — MISSING_LOCAL_BIN

**Severity** `warn` · **Confidence** `high` · **Affected targets** `posix-sh`, `cmd`, `powershell`

Script uses a local CLI tool that is not declared in dependencies or workspace bins.

## Why it breaks

- npm adds node_modules/.bin to PATH for script execution; an undeclared tool is not there. ([source](https://docs.npmjs.com/cli/v10/using-npm/scripts))
- Workspace packages expose their bin field to sibling scripts. ([source](https://pnpm.io/workspaces))

## Bad examples

- `vite build  (vite not in dependencies)`
- `jest  (jest not installed)`

## Good examples

- `vite build  (vite in devDependencies)`
- `my-workspace-tool  (workspace bin)`

## False positives

Only commands in the known-tool registry are checked — arbitrary words are never flagged. Declared dependencies and workspace package bins count as present.

## Fix (conditional)

Conditional: applied only when the required dependency is already installed; otherwise surfaced as a plan. `--fix` never installs dependencies.
