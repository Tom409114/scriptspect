# PS022 — POSIX_SOURCE

**Severity** `error` · **Confidence** `high` · **Affected targets** `cmd`, `powershell`

`source` (or `.`) requires a POSIX shell and fails under cmd.exe.

## Why it breaks

- `.` (dot) executes a file in the current shell — POSIX builtin; source is the bash synonym. ([source](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/V3_chap02.html#dot))

## Bad examples

- `source ./env.sh`
- `. ./scripts/env.sh`

## Good examples

- `node -r dotenv/config app.js`
- `bash ./env.sh`

## False positives

Only the dot form with a following argument counts; a bare `.` is not a source command.

## Fix (manual)

Manual: explained only — never applied automatically.
