# PS021 — POSIX_EXPORT

**Severity** `error` · **Confidence** `high` · **Affected targets** `cmd`

`export` is a POSIX shell builtin and fails under cmd.exe.

## Why it breaks

- export marks variables for the environment — a POSIX builtin. ([source](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/V3_chap02.html#export))
- cmd.exe uses `set` to define session variables; `export` is not recognized. ([source](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/set_1))

## Bad examples

- `export NODE_ENV=production`
- `export PATH=$PATH:./bin`

## Good examples

- `cross-env NODE_ENV=production node app.js`
- `node run-with-env.js`

## False positives

Not reported inside explicit shell wrappers.

## Fix (conditional)

Conditional: applied only when the required dependency is already installed; otherwise surfaced as a plan. `--fix` never installs dependencies.
