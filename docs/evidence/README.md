# Evidence ledger

Monthly, machine-drafted evidence of adoption and maintenance — generated by a GitHub Actions workflow from public GitHub/npm APIs only. Nothing is hand-typed; unverified numbers are never published.

## Tracked monthly (docs/evidence/YYYY-MM.md)

- **Adoption**: stars, forks, npm downloads, public repos using the Action/CLI, repeat downstream usage
- **Community**: external contributors/PRs/issues, repeat contributors, first-response time
- **Maintenance**: release cadence, triage counts, PR reviews, regression fixes, rule changes
- **Quality**: CI pass rate, parser/rule coverage, false-positive rate
- **Impact**: confirmed public cross-platform bugs found/fixed; upstream accepted fixes
- **AI leverage**: AI-assisted review/test/triage counts, including rejected suggestions

Principles: no fabricated metrics; no purchased or star-swapped adoption; third-party repos are never written to without explicit authorization.
